# MAGI 업무위임 검증 실행 명세

## 목적과 주장

목적은 사용자가 자연어로 목적과 제약을 맡겼을 때 MAGI가 필요한 조사·파일 작업·검증·교정을 수행하고, 새 사례에 재사용 가능한 교훈을 전이하는지 확인하는 것이다. 이 실행으로 주장할 수 있는 범위는 지정된 사례에서의 수행·오류복구·전이 관찰이다. 일반 자연어 계획 런타임, 일반 학습효과, 총 토큰 절감, 인간 시간 절감은 현재 근거로 주장하지 않는다.

## 현재 구현과 목표 구조

현재 근거는 SQLite 역할 메모리 어댑터(7 tests passed), local tracker·independent checker·review HTML(19 tests passed), 실제 파일 생성과 tracker 완료·review/reopen/recertification 실행이다. 목표 구조는 목적과 제약을 보존하는 역할 메모리, 별도 작업 등록, 실행 도구, 독립 검증, 교훈 추출, 새 과제 전이, 실패 시 교정과 철회를 연결하는 실행 루프다. 목표 요소가 현재 구현됐다고 간주하지 않는다.

## 실행 계약

판단 주체는 MAGI agent이며 인간은 목적·권한·안전 제약을 제공한다. 입력은 목표, 완료조건, 허용 경로·도구, 금지된 정답 유출 범위, 경험 사례다. 출력은 작업 파일, 보존된 요청·응답 calls.json, 사례별 판정, 오류·교정 로그, 비용(호출 수·토큰을 측정할 수 있을 때만), 교훈과 전이 결과다. 의존성은 tracker, 파일시스템, 독립 checker, 역할 메모리이며 실제 외부 서비스나 제품 설치는 이 프로토콜의 증거가 아니다.

각 실행은 (1) 기존 작업 조회·재사용 또는 child 작업 등록, (2) 학습 입력과 채점키 분리, (3) 경험 사례 수행, (4) 교훈을 추출하되 관찰·가설·규칙을 태깅, (5) 구조적으로 다른 전이 사례 수행, (6) 독립 checker가 산출물·금지조건·추적성을 판정, (7) 실패 시 국소 교정 후 재실행, (8) 결과와 비용 기록 순서로 진행한다. 예상 정답과 채점키는 학습 입력에 포함하지 않는다.

## 경험/전이 비교

G(경험 없음)는 해당 가족의 이전 사례·교훈 없이 수행한 기준선이다. F(고정규칙)는 사례를 일반화하지 않고 미리 적은 규칙만 적용한 조건이다. L(원문)은 경험 산출물·오류·교정 기록을 검색 가능한 형태로 제공하는 조건이다. E(추출교훈)는 L에서 관찰된 조건·행동·검증 결과를 짧은 교훈으로 추출해 전이 과제에 제공하는 조건이다. 동일한 ID나 값만 바꾼 과제는 전이로 인정하지 않으며, 표면 형식·자원·실패 원인·완료조건 중 둘 이상을 바꾼다. G/F/L/E를 같은 가족에서 각각 비교하고, 전이 과제에서는 정답 일치보다 새로운 제약에서의 실제 도구 행동과 독립 검증 통과를 본다.

## 실제 도구 행동 판정

파일 생성·수정은 파일 내용과 SHA-256으로 확인한다. tracker 작업은 등록 응답과 완료 응답으로 확인한다. checker는 별도 입력과 독립 규칙으로 확인한다. 단순 응답 문장, 저장·조회 성공, GPIO acknowledgement, 문서 서술만으로 실제 작업효과를 인정하지 않는다. 작업 목적과 다른 파일을 만들거나 금지 경계를 넘으면 실패다.

## 오류·교정·전체비용

오류는 입력 오해, 도구 실패, 산출물 불일치, 검증 실패, 전이 실패로 분류한다. 최초 실패 요청·응답도 calls.json에 남기고 원인에 맞는 국소 수정만 한다. 수정 후 같은 완료조건을 재검증하며, 재검증 실패면 교훈을 철회하고 G/F 조건으로 되돌려 재분해한다. 전체비용은 시도별 도구 호출 수, 입력·출력 토큰, 수정 횟수, 경과시간을 가능한 범위에서 기록하고 미측정 항목은 unknown으로 둔다.

## 반증·철회·재분해

독립 checker가 실패하거나, 경험에서는 통했지만 전이에서 구조적 차이를 처리하지 못하거나, 교훈이 정답을 유출해야만 성공하면 전이 주장을 반증한다. 교훈은 관찰과 다른 결과가 두 사례에서 반복되거나 적용 전제와 맞지 않으면 철회한다. 권한·목적·완료조건이 충돌하거나 한 단계가 두 책임을 섞으면 child 작업으로 재분해한다. 인간 승인은 새 취향·가치·권한 변경에만 요구한다.

## 미측정 한계

이번 명세만으로 자연어 계획의 일반성, 장기 기억의 안정성, 제품별 설치·벤치마크, 실제 물리 장비 효과, 총 토큰·시간 절감, 인간 반복 설명의 감소율을 측정하지 않는다. 작은 사례 수와 로컬 도구 의존성도 한계다.
