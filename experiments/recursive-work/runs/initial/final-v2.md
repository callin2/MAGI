# 첫 사용 안내 개정안

현재 사용자가 얻은 것은 검증 가능한 기반과 실행 기록이다. `role_memory.py`는 구현되어 7개 시험을 통과했고, 현재 작업도구와 독립판정기는 구현되어 17개 시험을 통과했다. 이번 비교·결정·안내 문서 작성도 실제 실행되어 파일 hash와 tracker 기록으로 남았다.

자연어로 업무를 맡기면 자동으로 일반 계획을 만들어 실행하는 기능은 목표 구조로 정해졌으며 아직 완성품으로 제공되지 않는다. 다음 실제 작업은 목적, 범위, 역할, 입력·출력, 완료 조건을 주고, adapter가 이를 구조화한 뒤 관련 교훈 조회와 계획 작성을 연결하는 구현이다. 실행은 기존 작업도구가 맡고 독립판정기가 결과와 hash를 확인한다. 사람은 실행 범위와 교훈 승격을 승인한다.

첫 검증에서는 같은 업무를 기억 없음·로그만·승인된 교훈 사용 조건으로 나누어 실행한다. 재설명, 오류, 시간, 모델 호출·토큰, 생성·검색 비용과 다른 업무 전이를 기록한다. 이 측정을 마치기 전에는 일반 학습 효과나 비용 절감을 주장하지 않는다. Hermes·Letta·OpenClaw는 설치·호환성 검증 전까지 설계 참고로만 취급한다.
