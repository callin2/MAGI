# 첫 사용 안내

이번 결정으로 사용자는 MAGI에 자연어로 목적과 완료 조건을 맡기고, 작은 adapter가 이를 기존 실행 도구에 연결하는 첫 작업 경로를 얻는다. 결과는 파일·로그·검증 근거와 함께 남고, 사람이 승인한 교훈만 다음 관련 세션에 다시 제공된다. 역할과 프로젝트 범위가 맞지 않거나 근거가 약한 내용은 자동 규칙으로 굳히지 않고 보류한다.

실제 업무를 맡길 때는 다음 네 가지를 한 번에 말하면 된다: 달성할 목적, 작업 범위와 역할, 사용할 입력·만들 출력, 완료를 확인할 방법. 실행이 끝나면 결과 파일과 검증 로그를 확인하고, 반복해서 유용했던 교정만 근거와 적용 조건을 붙여 교훈 후보로 승인한다. 잘못된 교훈은 archive하거나 이전 버전으로 되돌린다.

첫 검증에서는 같은 업무를 기억 없이, 로그만 사용해, 승인된 교훈을 사용해 각각 실행한다. 재설명·오류·시간·호출·토큰·생성/검색 비용과 다른 업무로의 전이를 기록해야 개선 여부를 말할 수 있다. 현재 산출물은 이 실행을 설계했으며, 제품 설치·실제 전이·범용 학습 효과를 이미 증명한 결과는 아니다.
