# MAGI 첫 실사용 구성 기술 결정 v3

## 판정 범위

현재 확인된 구현은 `role_memory.py`와 관련 7개 시험, 현재 작업도구·독립판정기와 관련 17개 시험이다. 이번 문서 작성과 tracker 처리는 실제 실행된 업무다. reflection 후보화·교훈 기록도 이번 실행에서 수행된 사실이다. 이 사실들은 자연어 요청을 일반 계획으로 만드는 런타임이 완성됐다는 뜻이 아니다. 일반화된 자연어→계획→실행 연결은 다음 구현을 위한 목표 구조다.

## 추천 목표 구성과 책임

작은 adapter, 기존 실행 도구, 파일/git 기반 지속 저장소, JSON 자료 계약을 목표 구성으로 한다.

| 단계 | 책임 | 입력 | 출력 | 현재 상태 |
|---|---|---|---|---|
| 1. 요청 정리 | adapter | 자연어 목적, 범위, 역할, 완료 조건 | 구조화된 작업 요청 | 목표 구조; 일반 자연어 런타임 미구현 |
| 2. 교훈 조회 | memory 계층 | 역할·프로젝트 ID, 구조화된 요청 | 관련 교훈과 revision, 근거·적용 조건 | role memory 구현·7시험 통과; 일반 검색/전이 미검증 |
| 3. 계획 작성 | adapter | 요청, 교훈, 허용 도구 | 단계, 책임, 입출력, 검증 조건 | 목표 구조 |
| 4. 실행 | 기존 작업도구 | 계획과 허용 범위 | 파일 변경, 명령 결과, 로그 | 작업도구·독립판정기 구현·17시험 통과 |
| 5. 판정 | 독립판정기 | 산출물, hash, 시험·로그 | 통과/실패, 미검증 목록 | 현재 구현 범위에서 확인 |
| 6. 교훈 후보화·채택·철회 | agent | 결과, 교정, 원인 가설, 기존 목적·제약 | 승인·보류·철회된 교훈 후보 | 이번 후보화는 실행됨; 일반 자동계획 런타임은 미구현 |

실행 경로는 `자연어 요청 → 구조화 → 관련 교훈 조회 → 계획 → 기존 작업도구 실행 → 독립판정 → 교훈 후보화/채택/철회`다. 기존 목적과 제약 안에서는 agent가 기술 판단, 검증, 교훈 채택과 철회를 진행한다. 새 취향·가치 판단·권한 변경이 필요할 때만 인간 판단을 요청한다. 이 문서는 모든 작업에 새 인간 승인 게이트를 추가하지 않는다.

## 선택 근거와 검증

Hermes의 profile·memory 분리, Letta의 정체성·git versioning, OpenClaw의 archive/restore는 설계 참고다. 세 제품을 설치하거나 성능을 비교한 결과가 아니다. 같은 과제를 no-memory, 로그만, 승인된 lesson 조건으로 실행해 재설명·오류·시간·호출·토큰·생성/검색 비용과 전이를 측정한다. 현재 시험 통과는 구현·도구 시험 근거이며 자연어 계획 일반성이나 교훈 전이 효과를 증명하지 않는다.

제품 설치·호환성, 세션 간 전이, 충돌·철회 효과, 범용 학습과 비용 절감은 미검증이다. reflection 후보화가 실제 수행됐다는 기록과 일반화된 자동계획 런타임이 없다는 판정은 별개의 증거다.
