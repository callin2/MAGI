# 첫 사용 안내 v3

현재 사용자는 `role_memory.py`(7개 시험 통과), 작업도구·독립판정기(17개 시험 통과), 그리고 실제 문서·reflection 후보화 실행 기록을 얻었다. 자연어 요청을 일반 계획으로 바꾸는 자동 런타임은 아직 목표 구조이며 완성된 기능으로 제공되지 않는다.

기존 목적과 제약 안의 기술 판단, 검증, 교훈 후보화·채택·철회는 agent가 진행한다. 새 취향·가치·권한 변경이 생길 때만 사람의 판단이 필요하다. 업무는 목적·범위·입력·출력·완료 조건을 주면 adapter 목표 경로에 맞춰 구조화하고, 기존 작업도구가 실행하며 독립판정기가 결과를 확인한다.

다음 검증은 같은 업무를 기억 없음·로그만·승인된 교훈 조건으로 나누어 수행한다. 재설명, 오류, 시간, 호출·토큰, 생성/검색 비용과 다른 업무 전이를 기록한다. 제품 설치·호환성, 일반화된 계획 능력, 범용 학습 효과와 비용 절감은 이 기록이 끝날 때까지 미검증으로 둔다.
