# MAGI 업무위임 검증 실행 명세

## 목적과 주장
사람이 같은 설명·교정을 반복하지 않아도, 목적과 제약 안의 지적 작업을 수행하고 경험을 다음 별도 과제에 전이하는지를 검증한다. 이 실행은 파일 생성, tracker 완료, review/reopen/재인증까지의 현재 구현을 검증할 수 있다. 일반 자연어 계획 런타임, 일반 학습효과, 총 토큰·인간시간 절감은 아직 구현·측정되지 않았으므로 주장하지 않는다.

## 현재와 목표
현재는 SQLite role memory adapter(7 tests), local tracker·independent checker·review HTML(19 tests), 실제 파일 생성 및 tracker 상태 변경이 확인됐다. 목표 구조는 목적을 입력받아 경험을 조건에 맞게 검색하고, 새 과제를 실행하며, 결과·근거를 저장하고, 오류 시 교정·철회·재분해하는 실행 루프다. 목표 구조의 존재는 현재 구현의 증거가 아니다.

## 실행 계약
입력은 `current-facts.json`, 이 명세, cases의 과제 문장이다. 책임 주체는 현재 판단자인 agent이며 기존 목적·제약 안 기술 판단·검증·학습 채택·철회는 수행한다. 새 취향·가치·권한 변경만 인간 판단으로 남긴다. 출력은 protocol/cases/summary, tracker의 issue 상태, 각 산출물 SHA-256이다. 의존성은 지정 tracker와 state.json뿐이며, 학습 입력에는 예상 정답·채점키를 넣지 않는다.

## 비교군
G(경험 없음)는 해당 가족의 경험을 검색·제공하지 않은 실행이다. F(고정규칙)는 경험 없이 미리 적은 규칙만 적용한다. L(원문)은 경험 원문 전체를 그대로 제공한다. E(추출교훈)는 원문에서 조건·행동·검증·철회 조건만 추출해 제공한다. 동일한 과제를 G/F/L/E에 무작위 순서로 배치하고 결과, 교정 횟수, 재작업, 산출물 근거, 비용을 기록한다. 전이 과제는 이름·ID만 바꾸지 않고 입력 구조, 오류 형태 또는 복구 조건을 바꾼다.

## 실제 도구행동 판정
파일이 실제로 생성·변경되고 tracker가 해당 issue를 완료하며 독립 checker/review가 통과해야 성공이다. 기억 조회·출력만으로는 성공이 아니다. 완료 보고에는 비어 있지 않은 evidence와 SHA-256을 포함한다.

## 오류·교정·비용
실패한 요청·응답은 calls.json에 원문 그대로 남긴다. 오류는 국소 수정 후 동일 조건으로 재실행하고, 교정 횟수·추가 도구 호출·토큰·경과시간을 기록한다. 비용은 G/F/L/E별 호출 수와 토큰, 사람 개입 횟수로 비교하며 현재는 총 절감효과를 측정하지 않는다.

## 반증·철회·재분해
경험을 제공해도 전이 과제에서 G보다 개선되지 않거나, 예상 정답 유출 없이는 재현되지 않으면 전이 주장을 철회한다. 경험이 현재 목적·제약과 충돌하거나 근거가 없으면 채택하지 않고 철회한다. parent cycle·다른 parent 재사용·빈 evidence 완료가 발견되면 해당 작업을 재분해하고 tracker 복구 검증을 다시 수행한다.

## 미측정 한계
이번 실행은 소수의 합성 과제와 로컬 도구에 한정된다. 장기 기억 품질, 자연어 계획의 일반성, 다중 사용자·제품 환경, 총 토큰·시간 절감, Hermes/Letta/OpenClaw의 설치·벤치마크, 물리 장비 효과는 측정하지 않는다.
