사용자가 목적과 제약을 맡기면 MAGI는 기존 작업을 확인하고, 필요한 child 범위를 등록한 뒤, 파일·도구 호출·tracker 상태가 서로 맞는 실행 산출물과 독립 검증 결과를 돌려준다. 이번 결과는 세 가족(followup, dedup, recovery)에 경험 사례와 별도 전이 사례를 구성하고, 답 유출을 막는 실행 경계를 명시했다.

현재 구현 근거로는 로컬 메모리·tracker·review 흐름과 이 명세의 실행 절차를 주장할 수 있다. 일반 자연어 계획, 장기 학습효과, 총 비용 절감, 외부 제품 비교와 물리 장치 효과는 주장할 수 없다. 다음 실행은 각 사례를 G/F/E 조건으로 순차 수행하고 calls.json, checker, tracker evidence를 비교해 전이 성공·실패와 비용을 보고한다.
