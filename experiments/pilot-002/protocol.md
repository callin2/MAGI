# pilot-002: 현재 미결 쟁점의 개방형 판단

## 목표

최근 진행 중인 쟁점 3개에서 해석·가치 충돌·근거 한계·소수 견해·판단 변경 조건이 드러나는지 관찰한다. 찬성/반대 어느 쪽에도 정답 키를 두지 않는다. 실제 미결 사안의 결과를 예측하는 정확도 시험이 아니다.

## 고정 입력과 입장

공통 evidence-pack.json만 주고 외부 검색과 다른 응답 조회를 금지한다. 세 주체는 별도 새 문맥에서 다음 추상 우선순위를 각각 부여받는다: A=개방성·혁신·기회비용, B=권리·비가역 손실·분배, C=실행가능성·가역성·제도적 지속성. 결론을 지정하거나 관점을 무조건 옹호하도록 지시하지 않는다. 이 차이는 실험자가 부여한 조건이며 자발적 다양성 또는 실제 주민·권리자·국가의 대표 의견이 아니다.

응답은 각자의 최종 반환으로만 받고 세 응답자가 모두 끝나기 전에는 파일·GitHub·서로의 문맥에 기록·공개하지 않는다. 이후에는 결과를 고정·보존한다. 정보 비공유는 통계적 독립성이나 캐시·계정 격리를 입증하지 않는다.

## 기준선과 조정

추가로 새 중립 주체가 같은 입력만 읽고 단일 판단 기준선을 작성한다. 동일한 출력 형식·길이를 요청하지만 토큰·시간의 동일 예산은 계측하지 못하므로 효율 우월성은 판단하지 않는다. 세 우선순위 응답 이후 조정자가 경쟁 해석과 기준을 검토하고 비합의·조건부 판단을 남긴다. 조정자는 만장일치를 요구하지 않으며 결론 자체와 미해결 가치를 분리한다.

중립 기준선은 1생성 배치, 세 관점은 3배치, 조정은 추가 1배치다. 각 배치는 세 사례를 포함한다. 같은 모델 설정·소표본·조건부 실험이며 반복 실행과 모델 다양성은 없다.

## 사전 루브릭

아래 6항목을 각각 0~2점 또는 판정불가로 평가한다. 선호하는 정책 결론으로 점수를 주지 않는다.

1. 근거 충실성: 사실·당사자 주장·제안·미확인 상태를 구분하고 출처 ID를 연결한다.
2. 가치 충돌: 누가 이익·손실·위험을 부담하는지, 자료만으로 해소되지 않는 우선순위를 명시한다.
3. 경쟁 설명: 말바꿈 이상의 해석·기준 차이가 있고 무엇으로 구별할 수 있는지 보인다.
4. 조건부 권고: 적용 범위·위임·행동 조건·기각 가능한 대안을 구체화한다.
5. 이견 보존: 강한 반론·비합의·추가 정보로도 남을 가치 충돌을 지우지 않는다.
6. 재검토: 입장을 바꿀 관측·가치 변경·기간·종료 조건을 구별한다.

0=누락 또는 중대한 혼동, 1=일부 제시하나 추상적/불완전, 2=해당 사례의 구체 근거와 한계를 연결. 판정불가를 0점으로 환산하지 않는다. 가설의 높음/낮음은 확률로 취급하지 않는다.

## 평가 절차와 실패 판정

실제 답변을 본 뒤 입력·루브릭을 바꾸지 않는다. 답변 작성에 참여하지 않은 새 평가자가 중립 기준선과 조정 결과를 익명 ID로 평가한다. 출력 문구로 방식을 추측할 수 있으므로 완전 맹검은 아니다. 평가자 1명의 점수는 객관적 정답이 아니며 주 에이전트가 근거와 과장을 재검토하고 불일치를 보존한다.

조정이 사실 오류를 추가하거나, 소수 반론을 지우거나, 가치 충돌을 기계적인 절충안으로 숨기면 실패로 기록한다. 추가 효과가 없으면 없다고 보고한다. 점수만으로 최종 구조를 채택하지 않는다. 미래의 실제 결론이나 동일 예산 효율은 이번 완료 기준이 아니다.
