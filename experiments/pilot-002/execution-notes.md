# 실행상 변경과 재현 범위

- 사전 protocol.md는 평가자 한 명을 서술했으나 실제 평가는 같은 루브릭의 새 주체 두 명으로 확대했다. 둘은 서로의 응답을 보지 않았다. 입력·평가 항목·답변은 변경하지 않았다. 이 확대가 점수 신뢰도를 입증한 것으로 취급하지 않는다.
- 평가 ID는 Z17=조정, Z42=중립이다. 대응표를 평가자에게 주지 않았지만 출력 형식과 A/B/C 언급으로 방식을 추론할 수 있다. 완전 맹검이 아니다.
- 각 응답자와 중립 기준선은 사례당 700자, 전체3000자 이내 목표를 지시받았다. 조정자는 사례당1000자, 전체4000자 이내 목표를 받았다. 실제 토큰·정확한 지연·금액은 계측하지 못했으며 동일 예산 비교가 아니다. 글자 제한은 소프트 지시이지 강제 토큰 제한이 아니다.
- 독립 응답자 세 명은 최종 응답만 반환했고, 전원 완료 후 주 에이전트가 원문을 JSON 파일로 보존했다. 조정자와 평가자도 최종 응답을 반환한 뒤 저장했다. 원문의 주장을 수정하지 않았다.
- 모델 설정은 상위 에이전트에서 상속했다. 실제 모델 버전·온도·캐시·계정 격리·학습 데이터 노출 여부는 미확인이다.
- 사안이 현재 미결이라는 조건은 공개 자료의 관측 시점에 한정한다. 공식 안건이나 사건기록 전부를 검토하지 않았으므로 정보 고정 이후의 결론 또는 모든 개별 쟁점의 미결을 보장하지 않는다.

## 실행 지시의 공통 내용 — 로컬 경로 정규화

독립 A/B/C와 중립: evidence-pack.json만 읽고 그외 파일·다른 응답·외부 검색·중앙 상태·파일 기록·메시지·하위 생성 금지. 세 사례에 대해 최소2 경쟁 설명/원칙, 추천, 근거 출처, 사실 한계, 가치 충돌, 강한 반론, 판별 관측, 입장 변경 조건, 남는 이견을 JSON으로 제출. A/B/C의 추상 우선순위만 다르고 중립에는 우선순위를 부여하지 않음. 사실을 우선순위에 맞춰 바꾸거나 미래 결과를 발명하지 말 것.

조정자: evidence-pack.json과 a/b/c만 읽고 중립·프로토콜·그외 입력 접근 금지. 만장일치나 절충 강제 금지. 개별 입장, 사실 오류·기간 근거·제안/시행 혼동·법적 결론/규범 제안 혼동, 반론·불확실성과 결정권을 명시. 추가 사실 조사 주장을 하지 않음.

평가자 J1/J2: evidence-pack.json, protocol.md, assessment-input.json만 읽음. 각 후보·사례의 여섯 항목을0~2 또는null로 평가하고 근거·오류표식·전체 한계를 제출. 다른 평가자 의견·대응표·외부 검색 금지. 선호 정책·길이·절충 자체를 가점하지 않음. 루브릭의2점은 구체 근거와 한계의 연결이 필요함.

이는 공개용 정규화 지시 기록이며 전체 시스템 프롬프트나 실행 환경을 복제하지 않는다.

## 출처 접근의 한계

S6(AP)는 직접 열기에서 Internal Error가 반환되어 검색 도구가 제공한 기사 요약·본문으로 해당 반대 보도를 확인했다. 원문 전체를 검토한 것으로 취급하지 않는다. S1은 보도 내용을 확인했지만 공식 안건 원문은 확보하지 못했다. S2는 시민사회 요약, S4는 이해당사자의 입장이므로 공적 판결로 승격하지 않았다.
