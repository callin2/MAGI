# MAGI 실제 효과 검증 — 2026-10-18

## 결정 체크포인트

고객 결과 → 에이전트에게 맡긴 실제 업무에서 과거 경험이 반복 오류와 재설명을 줄이고, 비용을 감수할 가치가 있는지 판단한다.

관측된 간극 → 기존 새 세션 실험은 도구 계약을 고친 뒤 G/F/L/E 모두 17/17이었다. 기억 자체의 효과와 전체 비용은 미입증이다. 이번 소스 점검에서 `init`은 `done, evidence=[]` 상태를 받아들였다. 이는 `complete`가 거부하는 상태다. Windows 임시 디렉터리에서 실제 재현했으며 제품 DB와 관계없다.

다음 행동 → 기존 tracker와 역할 기억 adapter, 실제 실패·교정에서 이미 추출한 교훈을 재사용한다. 새로운 코드 수리와 새 검토 자료 작성 두 업무에서 독립 실행을 비교한다. 실험 도구 설명·입력·판정·중단 기준을 모델 실행 전 고정한다.

수용 증거 → 원본 실패, 각 실행의 도구 호출·파일·상태·기억 receipt·측정 가능한 usage, 사전 고정 판정 및 실패를 모두 보존한다. 통과한 코드 후보는 별도 리뷰 후 기존 소유 모듈에 반영한다. 실험 통과를 MAGI 전체의 우월성으로 확대하지 않는다.

## 사전 고정 비교

- G: 과거 경험 없음. 현재 요청, 필수 제약, 현재 자료, 도구 계약은 모두 동일.
- F: 기존 교훈의 rule/conditions만 고정 지침으로 제공.
- L: 실제 관측 이벤트 원문 제공.
- E: 기존 adapter가 조회한 조건부 교훈 제공.
- A: 해당 업무와 가장 관련 있는 교훈 제외.
- C: 해당 교훈을 의도적으로 잘못된 내용으로 바꾼 오염 탐침. 실제 기억 저장소에는 채택하지 않는다.
- R: 기존 adapter에서 해당 교훈을 철회하고 새 receipt로 조회.

주 비교는 두 업무 × G/F/L/E × 2회 = 16회. A/C/R은 각 업무 1회씩 6회로 총 22회. 탐침은 방향 확인용이며 효과 크기 추정에 합산하지 않는다. 고정 seed로 실행 순서를 섞고 매번 새 대화·별도 파일 상태로 시작한다. 모델에게 평가 키, 다른 조건의 결과, 이전 대화를 주지 않는다. 임의의 AGENTS/확장/MCP/도구 검색도 로드하지 않는다.

코드 업무는 기존 tracker의 import 완료 상태 검증을 고치고 회귀 시험을 작성한다. 문서 업무는 현재 공개 소스와 검토 제안으로부터 사용자가 받을 수 있는 것과 다음 할 일을 구분한 인계 자료를 만든다. 두 업무 모두 실제 파일 생성과 기존 tracker의 작업·근거 완료를 요구한다. 파일 존재와 해시는 내용의 정당성과 별도로 검사한다.

요청·schema·판정 코드·기존 소스·교훈·실행 순서의 SHA-256은 `experiments/effectiveness-20261018/frozen.json`에 고정한다. 모델은 기존 Pi 연결의 `atomic-8317/gpt-6-luna`를 전 조건에서 사용한다. 이는 서버가 제공한다고 응답한 모델 이름이며 내부 가중치는 검증하지 않는다. bounded 반복 작업은 저비용 모델을 쓰라는 사용자 원칙을 적용한다. client reasoning parameter는 보내지 않아 서버 기본값이다.

사전 점검에서는 실험 실행기의 timeout 소수점 오류, 그리고 Pi에 등록됐지만 서버가 제공하지 않는 `gpt-5.5-medium` 오류가 각각 발견됐다. 모두 기록을 보존했다. 실제 `/models` 목록을 조회해 `gpt-6-luna` 지원을 확인했고, 기존 연결에서 호출 모델 ID만 바꾼다. 사용자의 Pi 설정 파일은 수정하지 않는다. 이는 본 실험 입력·결과 생성 전에 결정했다.

각 실행은 모델 응답 최대 16회, 도구 60회, 5분, 응답당 최대 8,192 output token으로 제한한다. 자동 재시도·대화 압축·사후 교정 프롬프트는 없다. 전송 장애는 해당 실행 실패로 보존하며 두 번 연속 전송 장애면 공급자 상태를 조사하고 남은 실행을 중단한다. 응답 timeout은 실행 중지 여부를 확인한 뒤 처리한다. 실패를 없애려고 같은 실행을 다시 생성하지 않는다.

전체 성공 = schema + 숨겨진 업무 판정 + 실제 파일/hash/tracker 완료 + 기존 회귀 유지. 각 축과 최초 실패/복구도 따로 보고한다. 실행 후 평가 오류가 발견되면 원평가를 보존하고 영향받은 비교를 무효 표시한다. 코드 업무에는 정상 완료 import와 변경된 증거를 reopen할 수 있는 반례를 포함해 과잉 거부를 검출한다.

usage는 제공자가 반환한 input/output/cache 수치를 보존한다. proxy의 0 가격을 무료라고 해석하지 않는다. 기존 교훈 생성·사람 리뷰 시간과 이번 조정자의 전체 비용은 관측 불가하면 unknown으로 남긴다. 따라서 이번 실행 단계 비용을 전체 생애 비용으로 부르지 않는다. 사람의 시간 절감, 다른 모델/프로젝트 일반화, 다중 협의 자체의 추가 이득은 이번 비교가 입증하지 않는다.

공유 작업 현황은 기존 fleet client로 현재 native session에 등록했다. `work_status`/`shared_context` MCP는 이 세션에서 제공되지 않아 중앙 공유 원칙의 새 조회·적용 증명은 unavailable이다. 실험이 새로운 상태 서버나 개발 DB를 만들지는 않는다. SQLite 파일은 기존 MAGI adapter의 재현 가능한 실험 fixture다.
